1Introduction to Computer Networks

A computer network is a collection of two or more interconnected computers and other devices that communicate with one another and share data, resources, and services.

The devices in a network may include:

  • Computers
  • Servers
  • Smartphones
  • Printers
  • Routers
  • Switches
  • Access points
  • Storage devices
  • IoT devices

The devices communicate through communication links and follow a set of rules called protocols.

Device A  —— communication medium ——  Device B

If many devices are connected and can exchange information, they form a network.

Important
A network is therefore not merely a collection of computers. It includes devices, communication media, networking equipment, addressing methods, protocols, and services.
2Goals of Computer Networks

The major goals of computer networking are the following.

1Data Communication

A network allows information to be transferred from one device to another.

Examples
Sending a message · Sending an email · Uploading a file · Watching an online video

2Resource Sharing

Hardware and software resources can be shared among multiple users.

Examples
One printer used by many computers · Shared storage · Shared applications · Shared internet connection

3Communication

Networks provide fast communication between people and systems.

Examples
Email · Text messaging · Voice calls · Video conferencing

4Remote Access

A user can access resources or systems from a different location.

Examples
Remote desktop · Accessing college servers · Cloud computing · Online banking

5Reliability and Availability

Networks can provide alternative paths or duplicate resources so that services can remain available even when one component fails.

6Scalability

A good network can be expanded by adding more devices, users, or services without completely redesigning the system.

7Centralized Management

In many network architectures, resources and users can be centrally managed, monitored, and secured.

3Applications of Computer Networks

Applications are the practical areas where computer networks are used.

Important
Do not confuse "goals" with "applications." For example: Resource sharing is a goal. Printer sharing is an application of that goal.

Major applications include:

ApplicationDescription
CommunicationEmail, instant messaging, voice calls, and video conferencing.
File and Data SharingUsers can exchange files and access shared databases.
Resource SharingPrinters, storage systems, internet connections, and software can be shared.
Remote AccessUsers can access computers, servers, and services from distant locations.
Internet and Web ServicesBrowsing websites, search engines, cloud platforms, and web applications all depend on networks.
Online EducationOnline classes, learning management systems, video lectures, and digital examinations use computer networks.
Online Banking and E-CommerceBanking transactions, payments, shopping, and order processing depend on networks.
EntertainmentOnline gaming, video streaming, music streaming, and cloud gaming use computer networks.
Distributed ComputingDifferent computers can cooperate to perform a task.
Social NetworkingSocial media platforms allow users to exchange information and communicate through networks.
4Network Structure

Network structure describes the components of a network and how those components are physically or logically connected. A network structure generally includes:

  1. Nodes / End Devices — Devices that send or receive data. Examples: Computer, Mobile phone, Printer, Server.
  2. Transmission Media — The medium through which data travels. Examples: Twisted pair, Coaxial cable, Optical fiber, Radio waves.
  3. Networking Devices — Devices that connect, forward, or control network traffic. Examples: Switch, Router, Hub, Access point.
  4. Protocols — Rules that control communication.
  5. Addressing — Devices need identifiers so that data can reach the intended destination.
Network Structure = Devices + Links + Networking Equipment + Protocols
5Network Architecture

Network architecture is the overall design and organization of a network. It describes how devices communicate, how services are provided, and how different components work together.

Two important architectures are:

  1. Client-Server Architecture
  2. Peer-to-Peer (P2P) Architecture
6Client-Server Architecture

In client-server architecture, a dedicated server provides services or resources to client devices.

Client: A device or application requesting a service.
Server: A system providing a service or resource.

Client 1 ——\ Client 2 ——— Server Client 3 ——/
Examples
Web server serving websites · Email server handling email · File server storing shared files · Database server providing database services
Advantages
  • Centralized management
  • Easier security control
  • Centralized data
  • Easier backup
  • Suitable for large networks
Disadvantages
  • Server failure can affect many clients
  • Server can become a bottleneck
  • More expensive and complex than simple peer-to-peer setups
7Peer-to-Peer Architecture

In a peer-to-peer network, computers can communicate and share resources directly with one another without requiring a dedicated central server. Each computer can act as both a client and a server.

PC A <——> PC B \ / \ / \ / PC C
Advantages
  • Simple for small networks
  • Lower cost
  • No dedicated server required
Disadvantages
  • Difficult to manage as the network grows
  • Security can be weaker
  • Backup and administration are decentralized
8OSI Reference Model

OSI stands for Open Systems Interconnection. The OSI model is a reference model developed to standardize and explain network communication. It divides communication into seven layers.

The seven layers from top to bottom are:

  1. Application
  2. Presentation
  3. Session
  4. Transport
  5. Network
  6. Data Link
  7. Physical
APSTNDP"Arey Pagle Suno Toh Nah Diaper Pehen"

The OSI model is important because it divides a complicated networking process into smaller, understandable functions. Each layer has a particular responsibility and communicates with the layers immediately above and below it.

9Detailed Explanation of All 7 OSI Layers

Layer 7Application Layer

The Application Layer is the top layer of the OSI model. It provides network services that are used by end-user applications.

Examples of services: Email · Web access · File transfer · Network resource access

Important point
The Application Layer does NOT mean the entire application itself. It provides network-related services that applications use.

Common protocols: HTTP, FTP, SMTP, DNS

Exam Answer
"The Application Layer provides network services to end-user applications such as web browsing, email, and file transfer."

Layer 6Presentation Layer

The Presentation Layer is concerned with the representation and format of data.

Major functions:

  1. Translation — Converts data between different formats or representations.
  2. Encryption and Decryption — Protects data by converting it into an encoded form and restoring it when required.
  3. Compression and Decompression — Reduces the size of data for efficient transmission and restores it at the destination.
Easy memory
Presentation = "How should the data be presented?"
Exam Answer
"The Presentation Layer handles data translation, encryption/decryption, and compression/decompression so that information is represented in a form understood by communicating systems."

Layer 5Session Layer

The Session Layer manages communication sessions between applications.

Major functions:

  1. Establishes a session
  2. Maintains/manages the session
  3. Synchronizes communication
  4. Terminates the session

A session is a logical conversation between communicating applications. For example, when two systems communicate continuously, the Session Layer helps manage that conversation.

Important distinction
Do not write simply: "Session Layer keeps the connection alive." Better: "The Session Layer establishes, manages, synchronizes, and terminates sessions between applications."

Layer 4Transport Layer

The Transport Layer provides end-to-end delivery of data.

Major functions:

  1. Segmentation — Large data is divided into smaller units.
  2. Reassembly — The units are reassembled at the destination.
  3. Error control — Helps detect and recover from transmission problems.
  4. Flow control — Prevents a fast sender from overwhelming a slower receiver.
  5. Reliable delivery — In reliable transport, mechanisms can ensure data reaches the destination correctly and in order.
  6. End-to-end delivery — Communication is handled between source and destination systems.
Important correction
Encryption/decryption is primarily associated with the Presentation Layer, not the Transport Layer in the basic OSI model.
Exam Answer
"The Transport Layer provides end-to-end delivery and performs segmentation, reassembly, flow control, error control, and reliability functions."

Layer 3Network Layer

The Network Layer is responsible for delivering packets across different networks.

Major functions:

  1. Logical addressing — Uses logical addresses such as IP addresses.
  2. Routing — Determines a suitable path for packets.
  3. Packet forwarding — Forwards packets toward their destination.

The Network Layer is especially important when source and destination are on different networks.

Computer A | Network 1 | Router | Network 2 | Computer B

The Network Layer helps determine how packets travel from A to B.

Exam Answer
"The Network Layer provides logical addressing, routing, and packet forwarding to deliver packets from source to destination across interconnected networks."

Layer 2Data Link Layer

The Data Link Layer provides reliable node-to-node delivery over a single link.

Major functions:

  1. Framing — Data is organized into frames.
  2. MAC addressing — Uses physical/MAC addresses for local delivery.
  3. Error detection — Detects certain transmission errors.
  4. Node-to-node delivery — Transfers frames between directly connected network nodes.
Important
At this layer, the data unit is a FRAME. Do not call it a packet when specifically discussing the Data Link Layer.
Exam Answer
"The Data Link Layer provides node-to-node delivery using frames and MAC addresses and performs functions such as framing and error detection."

Layer 1Physical Layer

The Physical Layer is the lowest OSI layer. It deals with the actual transmission of raw bits over a physical medium.

It defines characteristics such as: Electrical signals, Optical signals, Radio signals, Connectors, Cables, Signal levels, Physical transmission.

The Physical Layer converts bits into signals suitable for transmission.

Important
The Physical Layer deals with BITS and SIGNALS. It does not deal with packets as its basic data unit.
Exam Answer
"The Physical Layer transmits raw bits over the communication medium using electrical, optical, or radio signals."
10OSI Layer Data Units

A very important sequence — as data descends through Application, Presentation, and Session it stays as DATA, then:

LayerData Unit
Application / Presentation / SessionData
TransportSegment
NetworkPacket
Data LinkFrame
PhysicalBits
DATA  →  SEGMENT  →  PACKET  →  FRAME  →  BITS

At the receiver, the process is reversed:

BITS  →  FRAME  →  PACKET  →  SEGMENT  →  DATA

This concept is called encapsulation and decapsulation.

↓Encapsulation

When data moves down the OSI layers at the sender, each layer can add its own control information: Application data → Transport adds information → Segment → Network adds information → Packet → Data Link adds information → Frame → Physical sends bits/signals.

↑Decapsulation

At the receiver, information is processed upward through the layers: Bits → Frame → Packet → Segment → Data.

12Network Topology

Network topology is the physical or logical arrangement of devices and connections in a network. It describes how network devices are connected.

Common topologies: Bus, Star, Ring, Mesh. Other topologies exist, but these are fundamental syllabus topics.

13Bus Topology

In Bus Topology, all devices are connected to a common backbone cable.

PC —— PC —— PC —— PC ════════ Common Backbone ════════
Advantages
  • Simple design
  • Requires less cable
  • Relatively inexpensive for small networks
Disadvantages
  • Failure of the backbone can affect the network
  • Troubleshooting can be difficult
  • Performance can decrease as traffic increases
  • Collisions can occur in traditional shared-bus networks
Key phrase
"Single common backbone."
14Star Topology

In Star Topology, every device has a separate connection to a central networking device, usually a switch or hub.

PC | PC —— SWITCH —— PC | PC
Advantages
  • Easy to install
  • Easy to manage
  • Easy to identify a failed link
  • Failure of one cable normally affects only that device
  • Easy to expand
Disadvantages
  • Failure of the central device can affect the whole network
  • Requires more cable than bus topology
Important correction
Do not automatically say "router" as the central device. For a typical LAN Star Topology, the central device is usually a SWITCH or HUB.
Key phrase
"Central device."
15Ring Topology

In Ring Topology, each device is connected to two neighboring devices, forming a closed loop.

PC —— PC | | PC —— PC
Advantages
  • Organized data flow
  • Can provide predictable access in some ring protocols
Disadvantages
  • Failure can affect communication depending on the implementation
  • Adding or removing devices can be more complicated
Key phrase
"Closed loop."
16Mesh Topology

In Mesh Topology, devices have multiple interconnections. In a full mesh, every device is directly connected to every other device.

A ———— B | \ / | | \/ | | /\ | | / \ | C ———— D
Advantages
  • Very high reliability
  • Multiple paths exist
  • Failure of one link does not necessarily stop communication
Disadvantages
  • Very expensive
  • Requires large amounts of cable/ports
  • Complex installation and maintenance
Key phrase
"Multiple/direct connections."
17Transmission Media

Transmission media is the path or medium through which data signals travel from one device to another. It is broadly divided into Guided Media and Unguided Media.

TypeDescriptionExamples
Guided MediaSignals travel through a physical medium.Twisted pair, Coaxial cable, Optical fiber
Unguided MediaSignals travel through free space without a physical cable.Radio waves, Microwaves, Infrared
Simple distinction
Guided = physical path  |  Unguided = wireless/free-space path
18Guided Transmission Media

Guided media provides a physical path for signals. The three major types are Twisted Pair, Coaxial Cable, and Optical Fiber.

19Twisted Pair Cable

Twisted pair cable consists of two insulated copper wires twisted around each other. The twisting helps reduce electromagnetic interference and crosstalk.

Types commonly encountered: UTP — Unshielded Twisted Pair  |  STP — Shielded Twisted Pair

Advantages
  • Low cost
  • Easy to install
  • Widely used in LANs
  • Flexible
Disadvantages
  • More susceptible to interference than optical fiber
  • Limited distance and bandwidth compared with fiber
Key phrase
"Two twisted copper wires."
20Coaxial Cable

A coaxial cable contains a central conductor surrounded by insulation, a metallic shield, and an outer protective covering.

Outer jacket → Shield → Insulation → Central conductor

The shielding provides protection against interference.

Advantages
  • Better shielding than ordinary twisted pair
  • Can support relatively high bandwidth
  • Strong and reliable
Disadvantages
  • Thicker and less flexible than twisted pair
  • More difficult to install than simple twisted pair
Key phrase
"Central conductor + insulation + metallic shield."
21Optical Fiber

Optical fiber transmits data using pulses of light. It generally consists of: Core, Cladding, and Protective coating/jacket.

The core carries light. The cladding surrounds the core and helps keep light confined through the principle of total internal reflection.

Advantages
  • Very high bandwidth
  • Very high data rates
  • Low signal loss over long distances
  • Resistant to electromagnetic interference
  • Good for long-distance communication
Disadvantages
  • Higher installation cost
  • More delicate than ordinary copper cables
  • Joining and repair can require specialized equipment
Key phrase
"Light through glass/plastic fiber."
22Unguided Transmission Media

Unguided media transmits signals through free space. It is commonly called wireless transmission. Major examples for this syllabus: Radio waves, Microwaves, Infrared.

23Radio Waves

Radio waves are electromagnetic waves used for wireless communication. They can be used for: Broadcasting, Wireless communication, Mobile communication, Various radio-based systems.

Radio waves can travel over relatively large areas depending on the frequency, power, antenna, and environment. Signal quality can be affected by: Noise, Interference, Obstacles, Distance.

Key phrase
"Wireless electromagnetic communication over radio frequencies."
24Microwaves

Microwaves are electromagnetic waves with relatively high frequencies. They are commonly used for directional communication. A major characteristic is line-of-sight transmission for many terrestrial microwave systems.

Applications include: Point-to-point communication, Long-distance communication, Satellite communication, Wireless backhaul. Microwave links may cover long distances when relay stations are used.

Important correction
Bluetooth should not be used as the standard example when asked specifically about microwave communication in a basic networking answer. Bluetooth is generally classified as a radio-based wireless technology operating in the 2.4 GHz ISM band.
Key phrase
"Directional, often line-of-sight wireless communication."
25Infrared

Infrared communication uses infrared electromagnetic radiation.

Characteristics: Short range, Generally line-of-sight, Does not normally pass through opaque physical obstacles.

Example
Television remote control · Remote control of set-top boxes and similar devices
Advantages
  • Simple short-range wireless communication
  • Does not normally interfere with radio communication in the same way
Disadvantages
  • Short range
  • Obstacles can block the signal
  • Not suitable for many long-distance applications
Key phrase
"Short-range, line-of-sight wireless communication."
26Line Coding

Line coding is the process of converting digital data, represented as bits (0 and 1), into digital signals suitable for transmission over a physical medium.

Digital Data (0s and 1s) → LINE CODING → Digital Signal → Transmission Medium

Example: Data: 1010 — A line coding scheme decides how each 1 and 0 will be represented by signal levels or transitions.

Note
Line coding is a Physical Layer concept.
27Purpose of Line Coding

Line coding is used to:

  1. Represent digital bits as signals.
  2. Allow digital data to travel through a communication medium.
  3. Help receiver synchronization.
  4. Control signal characteristics.
  5. Improve transmission efficiency depending on the scheme.
  6. Reduce undesirable signal properties in suitable schemes.

Different schemes use different voltage levels and/or transitions.

28Unipolar Line Coding

In basic unipolar encoding, only one non-zero voltage polarity is used.

Typical representation: 1 = +V  |  0 = 0V

Data10110
Signal+V0+V+V0

The exact waveform depends on the duration and timing convention.

Advantages
  • Very simple
  • Easy to understand and implement
Disadvantages
  • Contains a significant DC component
  • Poor synchronization for long sequences without transitions
  • Not efficient for practical high-speed communication
Exam definition
"Unipolar line coding represents one binary value by a positive voltage and the other by zero voltage."
Key memory
UNIPOLAR = +V and 0V
29Polar Line Coding

Polar encoding uses two voltage polarities.

Typical basic representation: 1 = +V  |  0 = −V

Data1010
Signal+V−V+V−V
Important
The exact assignment of 0 and 1 can depend on the particular polar scheme or convention. For basic exam questions, the common convention above is usually sufficient unless your textbook specifies otherwise.
Advantages
  • Uses positive and negative levels
  • Better DC characteristics than simple unipolar signaling in many cases
  • Can provide improved synchronization depending on the specific scheme
Key memory
POLAR = +V and −V
30Bipolar / AMI Line Coding

Bipolar encoding uses three signal levels: +V, 0V, −V.

In Alternate Mark Inversion (AMI): 0 = 0V. Successive 1s alternate between +V and −V.

Data101101
Signal+V0−V+V0−V

Notice that the first 1 is +V. The next 1 becomes −V. The next 1 becomes +V again. This alternating polarity helps avoid a constant DC level and can also make certain errors easier to detect.

Key memory
BIPOLAR = +V, 0V, −V   |   AMI: 0 → 0V, 1 → alternating +V/−V
Very important
Bipolar does NOT mean that 0 is represented by either +V or −V. In basic AMI: 0 is always 0V. Only successive 1s alternate polarity.
31Manchester Encoding

Manchester encoding represents each bit using a transition in the middle of the bit period. The middle transition provides timing information and therefore makes clock synchronization easier.

The exact assignment of 0 = one transition direction, 1 = opposite transition direction depends on the convention being used.

Most important exam concept
"Every bit has a transition in the middle of the bit period."
Advantages
  • Excellent synchronization
  • Receiver can recover timing from the signal
  • No long flat sequence without a transition in the middle
Disadvantage
  • Requires more signal transitions
  • Therefore requires greater bandwidth than some simpler schemes
Key memory
MANCHESTER = MIDDLE TRANSITION

33Switching

Switching is the process of selecting or establishing a path through a network so that data can travel from source to destination. In a large network, the source and destination are usually not directly connected — intermediate devices help forward the information.

The major switching methods in this syllabus are: Circuit Switching and Packet Switching.

34Circuit Switching

Circuit switching establishes a dedicated communication path between the sender and receiver before communication begins. Once established, the resources/path are reserved for that connection for the duration of the communication.

Classic example
Traditional telephone networks.
Sender —— dedicated path —— Receiver

Characteristics: Dedicated path · Connection establishment before data transfer · Reserved resources · Predictable path · Suitable for continuous communication

Advantages
  • Dedicated connection
  • Predictable performance after setup
  • No competition for the reserved path during the connection
Disadvantages
  • Resources remain reserved even when no data is being transmitted
  • Connection setup takes time
  • Inefficient for bursty computer data
  • A failure in the path can interrupt the connection
35Phases of Circuit Switching

Circuit switching generally has three phases:

Phase 1Circuit Establishment / Setup

A path is selected and established between the sender and receiver. Network resources are reserved for the connection.

Example
When a traditional telephone call is started, the network establishes a path before the conversation proceeds.

Phase 2Data Transfer

After the circuit is established, the actual data or voice information is transmitted through the dedicated path.

Phase 3Circuit Disconnect

When communication ends, the connection is terminated and the reserved network resources are released.

SETUP → TALK/TRANSFER → DISCONNECT
36Packet Switching

In packet switching, data is divided into smaller units called packets. The packets are transmitted through a shared network rather than reserving one complete dedicated path for the entire communication.

Large message → Packet 1 → Packet 2 → Packet 3 → Packet 4

The packets may be forwarded through the network using available resources.

Characteristics: No dedicated end-to-end circuit is required · Network resources are shared · Data is divided into packets · Packets contain addressing/control information · Efficient for bursty computer communication

Advantages
  • Efficient use of network resources
  • Good for bursty data
  • Many users can share the network
  • More flexible than dedicated circuit switching
Disadvantages
  • Variable delay
  • Packets may experience congestion
  • Packets can potentially be lost or arrive out of order, depending on the network and protocol
  • Quality may vary during heavy traffic

38Time Division Multiplexing (TDM)

TDM stands for Time Division Multiplexing. Multiplexing means combining multiple signals so that they can share a common communication channel.

In TDM, multiple users/signals share the same communication channel by being assigned different time slots.

User A → Time Slot 1 User B → Time Slot 2 User C → Time Slot 3 User D → Time Slot 4

Then the cycle repeats:

A | B | C | D | A | B | C | D |

All users use the same physical channel, but at different times.

⚙How TDM Works

Suppose four input sources need to communicate. Without multiplexing, each source may need a separate channel. With TDM, one shared channel is divided into repeating time slots.

Frame: A | B | C | D | Next frame: A | B | C | D | A ——\ B ———\ C ————→ MULTIPLEXER —— Shared Channel —— DEMULTIPLEXER —→ A, B, C, D D ——/

A multiplexer at the sender combines the inputs. A demultiplexer at the receiver separates them again.

⚙Types of TDM

Two basic types often discussed: Synchronous TDM and Statistical / Asynchronous TDM.

TypeDescriptionAdvantageDisadvantage
Synchronous TDMEach input is assigned a fixed time slot in each frame, even if that input has no data to send. Example: A | B | C | D — even if C has nothing to send, its slot may remain unused.Simple, Predictable, Easy to manageWastes capacity when an assigned source has no data
Statistical TDMTime slots are dynamically assigned to sources that actually have data. Example: if A and C have data — A | C | A | C. Unused sources do not necessarily consume fixed slots.Better utilization, Efficient for bursty trafficMore complex, Requires additional addressing/control information

⚙Important TDM Terms

Time Slot: A small portion of time allocated to a particular input/source.
Frame: A repeating group of time slots.
Multiplexer: Combines multiple input signals into one shared output.
Demultiplexer: Separates the combined signal back into individual outputs.
Key memory
TDM = Same channel, different times.
39Important Definitions for Examination

Topology: The physical or logical arrangement of devices and connections in a network.
Transmission Media: The path through which signals travel from one device to another.

Unguided Media: Transmission media in which signals travel through free space without a physical cable.

41Common Mistakes to Avoid
Mistake 1
DO NOT confuse Network Layer and Data Link Layer.
Network Layer: IP, routing, packets.   Data Link Layer: MAC, frames, node-to-node delivery.
Mistake 2
DO NOT confuse Physical Layer with Data Link Layer.
Physical: Bits and signals.   Data Link: Frames and MAC addresses.
Mistake 3
DO NOT put encryption/decryption primarily under Transport Layer in a basic OSI answer. Encryption/decryption is associated with the Presentation Layer.
Mistake 4
DO NOT say the Star Topology always uses a router. The central device is normally a switch or hub in a typical LAN.
Mistake 5
DO NOT call Data Link data units packets. Data Link = Frames. Network = Packets.
Mistake 6
DO NOT call Physical Layer data units packets. Physical Layer = Bits/signals.
Mistake 7
DO NOT say Bluetooth is the standard example of microwave transmission in a basic answer. Bluetooth is generally classified as radio-based wireless communication.
Mistake 8
DO NOT confuse goals with applications.
Goal: Resource sharing → Application: Printer sharing.
Goal: Communication → Application: Email/video conferencing.
Mistake 9
DO NOT forget the three phases of circuit switching: Setup, Data transfer, Disconnect.
Mistake 10
DO NOT forget that Manchester's key feature is the transition in the middle of every bit period.
Mistake 11
DO NOT forget the special rule of AMI: 0 = 0V, 1 = alternating +V and −V.
Mistake 12
DO NOT describe Session Layer only as "keeping connection alive." Write: Establishes, manages, synchronizes, and terminates sessions.

Final Professor's Revision

If you remember only the following chains before entering the exam, you can reconstruct a large part of the chapter:

OSI: APSTNDP

Data Movement: Data → Segment → Packet → Frame → Bits

OSI Functions: Application → Services  |  Presentation → Format  |  Session → Session  |  Transport → End-to-end  |  Network → Routing  |  Data Link → Frames/MAC  |  Physical → Signals

Topology: Bus → Backbone  |  Star → Center  |  Ring → Loop  |  Mesh → Multiple links

Media: Guided → Cable  |  Unguided → Wireless

Guided: Twisted Pair → Copper  |  Coaxial → Shield  |  Fiber → Light

Line Coding: Unipolar → +V/0  |  Polar → +V/−V  |  Bipolar → +V/0/−V  |  Manchester → Middle transition

Switching: Circuit → Dedicated  |  Packet → Shared packets

Circuit: Setup → Transfer → Disconnect

TDM: Same channel → Different time slots

The central idea of the entire chapter is simple: A network allows devices to communicate. The OSI model explains the communication process layer by layer. Topology explains how devices are arranged. Transmission media explains how signals travel. Line coding explains how digital bits become digital signals. Switching explains how data moves through a network. TDM explains how multiple signals can share one channel by taking turns in time.
